清理残留状态

OCI IPv6 对象 0
仅允许删除未入池、非动态的 /128 对象；前缀段（如 /112）和系统 SLAAC 地址不会被删除。

说明

清理只影响本进程管理的资源，不会删除 WAN 网卡或 ISP 下发的地址。
OCI 模式会对比 OCI 控制台的 IPv6 对象：只清理未入池、非动态的本地 /128；/112 等前缀段和系统 SLAAC 地址始终保留。
如果删除虚拟网卡，正在使用 source_mode=pool 的实例需要重启后才会重新创建。
建议顺序：先「残留地址」，再按需「策略路由」，最后「虚拟网卡」。
